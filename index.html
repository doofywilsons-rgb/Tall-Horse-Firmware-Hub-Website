Saving, updates, and return paths

Backup/read-out

SLOOP/sloopDX and Felucca have distinct read-only capture adapters with simulated tests. The separate FiMba exporter can read its last saved project in laboratory testing; stock FiMba cannot.

Firmware update

Having an OTA/update loader in an OS does not prove Tall Horse can preserve projects while switching to a different OS. Device identity, exact target and recovery route must be checked independently.

Restore and rollback

No firmware-to-firmware safe return route is recorded as hardware-verified. Interrupted updates must never automatically bypass safety gates or clear restrictions.

One ZIP, automatically organized
