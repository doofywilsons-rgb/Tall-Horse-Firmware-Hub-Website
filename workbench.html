Connect and explore

  1. Use a computer: Open the official Workbench in desktop Chrome or Edge. Android browsers may not expose the Web MIDI / SysEx access the hardware tool needs.
  2. Connect FM-1: Use a USB data cable and choose Connect Device in Workbench. Approve the browser's MIDI / SysEx permission only for your intended FM-1.
  3. Edit: Select a built-in preset or read the device project. Saving in the browser is different from writing to the device.
  4. Save with care: If using Save to device, confirm the correct slot. It replaces that slot; wait for Workbench's read-back verification before disconnecting.

Backup checklist

The checkboxes are private notes saved only in this browser. They do not detect the FM-1 or prove that a backup exists.

.fm1 projects do not include the sample audio; keep .fm1s separately. Restoring a project into Workbench does not automatically write it to the hardware.

Compatibility and next steps
