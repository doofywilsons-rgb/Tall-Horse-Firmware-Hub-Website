# Contributing

Tall Horse Firmware Hub is an independent FM-1 firmware research and documentation project.

Please open an issue to propose catalog corrections, missing source credits, safe protocol research or documentation improvements. Include the firmware name, exact version and upstream source; avoid unverified claims about backup, recovery or hardware flashing.

Do **not** submit proprietary firmware files, personal device backups, credentials or binaries without documented redistribution rights. This repository documents hardware-unverified experiments, not approved automatic firmware switching.

Respect upstream licenses and original developers. Tests on simulators must be labeled *simulated* until reproduced safely on supported hardware.
